# 校验样例集:10 场景跨域压测

> **这是插件的验证案例集,不是插件的一部分。** 插件是通用组件;本目录仅记录一次
> 系统性压测的场景与战果。通用逻辑/注释不含任何案例内容(纯度守卫把关)。

## 场景清单(每场域只作校验样例)

| # | 场景 | 压测面 | 发现的插件缺陷 |
|---|---|---|---|
| 1 | 数据管道 ETL | 数值规格/多级 verify/基线指标 | #2 取数脆弱 |
| 2 | KV 存储 HTTP 服务 | 长驻进程/并发不变量/浸泡 | #3 固定超时 |
| 3 | semver 范围求解器 | 属性测试/probe/文法边界 | #4 交替捕获组 |
| 4 | API 文档生成器 | 衍生品 vs 交付物/覆盖 | #5 AC 静默丢弃 |
| 5 | jq 式 CLI 过滤器 | 退出码族谱/错误路径 | #6 exit=N |
| 6 | 热路径性能优化 | 基准噪声/逼优 | #7 容差 |
| 7 | 交通流模拟器 | 确定性/守恒/快照 | #8 诊断失明 |
| 8 | 安全加固靶场 | 红→绿/自证探针 | (防线全数扛住,零新增) |
| 9 | 无障碍+国际化 | 覆盖率/ANSI 输出 | #9 ANSI 盲区 |
| 10 | 多模块工具包 × 多成员 | 团队桥/repair/claim | #10 delta 饱和 |

另:#1(轮次作用域)发现于压测设计期。完整缺陷细节见 docs/defect-ledger.md。

## 战果

- 10/10 场景 GO 1.0;10 条插件缺陷全部修复 + 回归测试;红队 8/8
- 运营发现:多成员循环需要队长看门(队员回合被回收时调度器不自动重启)
- 验证体系沉淀:证据绑定评审、自证探针、验证金字塔、fail-closed 解析、诊断进结果
